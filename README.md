# Deepfake Demo

Самостоятельная студия для гостевых звонков на Vinteo и проверки методов обработки видео. Обработка кадров выполняется на этой машине.

## Запуск

Node 22.22, Yarn Classic. Выполните `yarn install --frozen-lockfile`, один раз `yarn model:detector`, затем `yarn start`. Electron откроет студию. Браузерная версия доступна на http://localhost:3000. Адрес сервера вводится как имя или имя с портом. SIP Connector подключается по WSS к `/webrtc/wss/`. Сервер должен разрешать гостевые звонки и иметь доверенный TLS-сертификат. Камера и микрофон по умолчанию выключены. Выберите устройства и включите нужные перед звонком.

## Сборка и проверка

Команды `yarn build:mac`, `yarn build:win`, `yarn build:linux` создают соответственно DMG, установщик NSIS и AppImage в release/. Запускайте команду на целевой ОС. macOS-сборка предназначена для локальной разработки, без Developer ID и нотарификации. `yarn test` проверяет нормализацию адресов, каталог адаптеров и распознавание лица моделью pico.

SIP и UA предоставляют публичные npm-пакеты sip-connector, @krivega/jssip и ua-parser-js. Репозиторий хранит только код приложения и явно указанные артефакты сторонних проектов. Камера и звук передаются адресату звонка, настройки сервера и результаты в приложении не сохраняются.

## Обработка видеопотоков

- **Генератор.** Включите камеру и «Демо-аватар · pico». Обученный каскад определяет положение и размер лица. Эти координаты управляют вымышленным рисованным персонажем. На выходе постоянно видна метка SYNTHETIC VIDEO / DEMO AVATAR. Выключение возвращает дорожку камеры. [Описание модели и права](src/makers/avatar/README.md).
- **Детектор.** При наличии входящего видео включите Deep-Fake Detector v2. Локальный Worker запускает ONNX Runtime Web и классифицирует декодированные кадры в разрешении 224 × 224. Модель обучена на снимках лиц. Раскладка конференции, рисунки и видеосжатие могут существенно менять оценку. Процент относится к отдельному кадру. [Карточка модели](https://huggingface.co/prithivMLmods/Deep-Fake-Detector-v2-Model).
- **Установка детектора.** Команда `yarn model:detector` загружает закреплённую ревизию ONNX, проверяет SHA-256 и подготавливает локальный WASM. Также принимает путь к уже скачанному файлу. Вес хранится в игнорируемой папке public/models. Выполните подготовку до сборки инсталлятора. При звонке модель загружается из локальных ресурсов только после включения детектора.
- **Размещение.** «Локальный клиент» означает браузерный renderer. «Локальный сервер» означает отдельный процесс на этой же машине. Варианты DeepFaceLive и FTCN отмечены недоступными. Фабрики в src/makers и src/detectors позволяют добавлять реализации по отдельности. У каждого работающего адаптера check проверяет возможности среды, start возвращает сеанс с методом stop.
- **Проверка декодированного видео.** При запущенном `yarn start` откройте консоль браузерной версии и выполните `await (await import('/src/detectors/classifier/loopback-fixture.js')).runLoopback()`. Фикстура использует два RTCPeerConnection на одной машине, получает декодированный кадр, вызывает настоящий детектор и проверяет состояние принимающей дорожки после остановки.
