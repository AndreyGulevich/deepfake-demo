# Deepfake Demo

Самостоятельная студия для гостевых звонков на Vinteo и проверки методов обработки видео. На первом этапе адаптеры моделей отключены.

## Запуск

Node 22.22, Yarn Classic. Выполните `yarn install --frozen-lockfile`, затем `yarn start`. Electron откроет студию. Браузерная версия доступна на http://localhost:3000. Адрес сервера вводится как имя или имя с портом. SIP Connector подключается по WSS к `/webrtc/wss/`. Сервер должен разрешать гостевые звонки и иметь доверенный TLS-сертификат. Камера и микрофон по умолчанию выключены. Выберите устройства и включите нужные перед звонком.

## Сборка и проверка

Команды `yarn build:mac`, `yarn build:win`, `yarn build:linux` создают соответственно DMG, установщик NSIS и AppImage в release/. Запускайте команду на целевой ОС. macOS-сборка предназначена для локальной разработки, без Developer ID и нотарификации. `yarn test` проверяет нормализацию адресов и каталог адаптеров.

SIP и UA предоставляют публичные npm-пакеты sip-connector, @krivega/jssip и ua-parser-js. Репозиторий хранит только код приложения и явно указанные артефакты сторонних проектов. Камера и звук передаются адресату звонка, настройки сервера и результаты в приложении не сохраняются.
