# Deepfake Demo

Самостоятельная студия для гостевых звонков на Vinteo и проверки методов обработки видео. Обработка кадров выполняется на этой машине.

## Запуск

Node 22.22, Yarn Classic. Выполните `yarn install --frozen-lockfile`, один раз `yarn model:detector`, затем выберите режим запуска.

- `yarn start` открывает студию в браузере по умолчанию на http://localhost:3003.
- `yarn start:electron` собирает интерфейс и открывает его в отдельном окне Electron. Команда работает независимо от браузерного сервера.

Адрес сервера вводится как имя или имя с портом. SIP Connector подключается по WSS к `/webrtc/wss/`. Сервер должен разрешать гостевые звонки и иметь доверенный TLS-сертификат. При открытии студия запрашивает камеру и микрофон. Каждое доступное устройство включается после получения разрешения. Камеру и микрофон можно выключать независимо.

## Сборка и проверка

Команды `yarn build:mac`, `yarn build:win`, `yarn build:linux` создают соответственно DMG, установщик NSIS и AppImage в release/. Запускайте команду на целевой ОС. macOS-сборка предназначена для локальной разработки, без Developer ID и нотарификации. `yarn test` проверяет нормализацию адресов, каталог адаптеров и распознавание лица моделью pico.

SIP и UA предоставляют публичные npm-пакеты sip-connector, @krivega/jssip и ua-parser-js. Репозиторий хранит только код приложения и явно указанные артефакты сторонних проектов. Камера и звук передаются адресату звонка, настройки сервера и результаты в приложении не сохраняются.

## Обработка видеопотоков

- **Генератор.** Включите камеру, выберите генератор и фотографию для замены лица. Для FakeFace Test Camera · GhostV2 запустите локальный обработчик командой `yarn start:ghostv2`.
- **Детектор.** В поле «Анализировать поток» выберите входящее видео конференции или исходящее видео с камеры. Исходящий режим работает без звонка и следует за генератором при его включении и выключении. Для смены направления выключите детектор. В реализации Deep-Fake-Detector-v2 на каждом измерении pico ищет лицо. Квадратная область вокруг найденного лица приводится к 224 × 224 и передаётся локальному Worker с ONNX Runtime Web. Если лицо не найдено, интерфейс убирает процент. Модель обучена на снимках лиц. Раскладка конференции, рисунки и видеосжатие могут существенно менять оценку. Процент показывает выход класса Deepfake для одного изображения лица. На настоящем лице тоже возможна высокая оценка. Калибровка для видеозвонков не проводилась. [Карточка модели](https://huggingface.co/prithivMLmods/Deep-Fake-Detector-v2-Model).
- **Установка детектора.** Команда `yarn model:detector` загружает закреплённую ревизию ONNX, проверяет SHA-256 и подготавливает локальный WASM. Также принимает путь к уже скачанному файлу. Вес хранится в игнорируемой папке public/models. Выполните подготовку до сборки инсталлятора. Модель загружается из локальных ресурсов после включения детектора.
- **Размещение.** «Локальный клиент» означает браузерный renderer. «Локальный сервер» означает отдельный процесс на этой же машине. DeepFaceLive Face Animator подключается к отдельному процессу LIA. FTCN+TT анализирует клипы из 32 кадров в отдельном локальном процессе. [Установка и запуск FTCN](integrations/ftcn/README.md). Фабрики в src/makers и src/detectors позволяют добавлять реализации по отдельности. У каждого работающего адаптера check проверяет возможности среды, start возвращает сеанс с методом stop.
- **Проверка декодированного видео.** При запущенном `yarn start` откройте консоль браузерной версии и выполните `await (await import('/src/detectors/classifier/loopback-fixture.js')).runLoopback()`. Фикстура использует два RTCPeerConnection на одной машине, получает декодированный кадр, вызывает настоящий детектор и проверяет состояние принимающей дорожки после остановки.

### DeepFaceLive Face Animator на macOS и Windows

Выбор «DeepFaceLive · Face Animator (LIA)» использует оригинальный ONNX-граф модуля Face Animator из DeepFaceLive. На Apple Silicon отдельный процесс использует Core ML с резервным расчётом на CPU. Активный провайдер указан в /health на порту 8765. Камера управляет движением выбранного портрета. В разделе «Генератор» можно выбрать JPEG, PNG или WebP до 20 МБ. Оставьте поле пустым для демо-лица. Квадратный портрет вписывается в кадр с пропорциями камеры. Полный графический пакет DeepFaceLive устанавливать не требуется. [Модуль в upstream](https://github.com/iperov/DeepFaceLive/blob/master/apps/DeepFaceLive/backend/FaceAnimator.py) · [Происхождение и проверка весов](integrations/deepfacelive/MODEL.md)

1. Установите 64-битный Python 3.11 для своей ОС. На Windows команда использует `py -3.11`, на Mac — `python3`. Переменная `DEMO_PYTHON` позволяет указать полный путь к интерпретатору.
2. Из корня проекта выполните `yarn setup:deepfacelive`. Команда создаёт отдельное окружение (.venv-deepfacelive-coreml на Apple Silicon), устанавливает зависимости и проверяет веса. Они хранятся вне Git. Для первого запуска нужен интернет.
3. Запустите `yarn start:deepfacelive` в отдельном терминале и оставьте его открытым. Затем откройте студию через `yarn start`. Её браузерный и Electron-интерфейсы подключаются к 127.0.0.1:8765. При отсутствии сервиса или модели список показывает причину. После запуска сервиса откройте список повторно.
4. Включите камеру, поместите лицо по центру и выберите Face Animator в разделе «Генератор». Включение фиксирует опорную позу по первому кадру. Каждая последующая обработка использует центральный квадрат изображения. Чтобы откалибровать позу заново, выключите и включите генератор. Звонок для локального просмотра не требуется.
5. Выключение генератора закрывает сеанс обработки и возвращает исходную дорожку камеры. Чтобы выгрузить модель и завершить процесс обработчика, нажмите Ctrl+C в его терминале.

В установленном Electron-приложении файлы отдельного сервиса также лежат в `Contents/Resources/deepfacelive` на macOS и `resources/deepfacelive` на Windows. Их можно скопировать в пользовательскую папку, создать там виртуальное окружение Python, выполнить в нём `python -m pip install -r requirements.txt`, `python prepare.py` и `python server.py`. Инсталлятор содержит код адаптера, веса скачиваются отдельно для локальной некоммерческой оценки. Авторы LIA указывают CC BY-NC 4.0. [Условия и происхождение модели](integrations/deepfacelive/MODEL.md).

### Deep-Live-Cam (hacksider)

Отдельный генератор использует процесс на 127.0.0.1:8766, исходный процессор замены лица Deep-Live-Cam и лицо с выбранной фотографии или встроенный демо-портрет. Для сравнения результатов используйте снимок с одним лицом в центре. Выбор блокируется во время обработки. Веса моделей устанавливаются пользователем отдельно от дистрибутива. [Установка и диагностика](integrations/deeplivecam/README.md) · [Условия использования](integrations/deeplivecam/TERMS.md).

### FakeFace Test Camera · GhostV2

Локальный обработчик использует SwapEngine из пакета коллеги версии 1.0.0, YuNet, CVLFace и GhostV2 в OpenVINO CPU. Комплект находится вместе с другими локальными моделями в `~/.cache/deepfake-demo/fakeface-test-camera`. Для другой машины извлеките из проверенного DEB каталог `opt/fakeface-test-camera` под этот корень, сохранив ссылку `app/models`. Создайте там Python 3.12 venv с именем `venv` и установите в него `openvino` и `opencv-python-headless`. Пути переопределяются через `GHOSTV2_KIT` и `GHOSTV2_PYTHON`. Установщик Linux для запуска обработчика в студии не требуется.

Запустите `yarn start:ghostv2`, затем выберите генератор в студии. Для своей фотографии используйте общий блок замены лица. Если фотография не выбрана, используется синтетический портрет из диагностической фикстуры. Когда YuNet не выделяет ровно одно лицо нужного размера, обработчик передаёт исходный кадр. Счётчик успешных замен доступен на `http://127.0.0.1:8768/health`.

### Сравнение детекторов

Для проверки без звонка выберите «Исходящий · после генератора». Чтобы сменить модель, выключите детектор, выберите другую реализацию и снова включите. Выбор модели не переключает камеру или генератор.

| Детектор | Где обрабатывается видео | Запуск |
| --- | --- | --- |
| MTL Face Auth | Локальный клиент, Web Worker в браузере | Один раз выполните `yarn model:mtl` |
| AltFreezing | Локальный сервер, отдельный процесс на порту 8769 | `yarn start:altfreezing` |
| SBI | Локальный сервер, отдельный процесс на порту 8770 | `yarn start:sbi` |

Процент относится к результату выбранной модели. Для сравнения используйте одинаковые клипы с лицом, включая запись обычной камеры.
