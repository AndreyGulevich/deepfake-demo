# Условия локального теста Deep-Live-Cam

Сверено 22 ноября 2026 года. **Пользователь подтвердил некоммерческое академическое исследование. Эта цель соответствует опубликованным условиям InsightFace для InSwapper и buffalo_l.** Запуск публичного кода из исходников доступен без подписки. Отдельная продуктовая оценка коммерческой ВКС потребует уточнить права. Для продуктового пилота InsightFace предлагает запросить доступ для технической оценки. [AGPL проекта, §2](https://github.com/hacksider/Deep-Live-Cam/blob/main/LICENSE) · [Условия InsightFace](https://www.insightface.ai/) · [Evaluation access](https://www.insightface.ai/contact)

Windows NVIDIA и AMD стоят $22 или $40 соответственно. На этих страницах отсутствует отдельное предоставление прав на использование моделей InsightFace в собственном приложении. [Mac](https://deeplivecam.net/index.php/plans/mac-silicon-edition/subscribe?group_id=3) · [NVIDIA](https://deeplivecam.net/index.php/plans/nvidia-gpu/subscribe?group_id=1) · [AMD](https://deeplivecam.net/index.php/plans/amd-gpu/subscribe?group_id=2) |
| InsightFace и модели | Код опубликован под MIT. README ограничивает опубликованные веса условием «non-commercial research purposes only», включая автоматическую загрузку. Сайт уточняет «Pre-trained models for non-commercial academic research only». За лицензией на семейство InSwapper, включая модель замены лица, обращаются по адресу `contact@insightface.ai`, по пакету анализа лиц `buffalo_l` — `recognition-oss-pack@insightface.ai`. При запросе укажите конкретные файлы, включая FP16-конверсию при её использовании, цели теста и предполагаемое распространение. [README и контакты](https://github.com/deepinsight/insightface#license) · [Правила правообладателя](https://www.insightface.ai/) |
| Улучшение лица GFPGAN | Tencent указывает Apache-2.0 с оговоркой «except for the third-party components listed below». Upstream Deep-Live-Cam ссылается на конвертированный `gfpgan-1024.onnx`. В карточке коллекции hacksider указано `gpl-3.0`, но отсутствуют описание происхождения и отдельные условия именно этого файла. Использование и включение этой конверсии в поставку требуют отдельной проверки. Это опциональный этап улучшения изображения. [GFPGAN LICENSE](https://github.com/TencentARC/GFPGAN/blob/master/LICENSE) · [Инструкция Deep-Live-Cam](https://github.com/hacksider/Deep-Live-Cam#installation) · [Карточка коллекции](https://huggingface.co/hacksider/deep-live-cam) |

ONNX Runtime опубликован под MIT, OpenCV начиная с версии 4.5 — под Apache-2.0. У FFmpeg лицензия зависит от состава сборки (LGPL-2.1-or-later или GPL при включённых GPL-компонентах). Если используется полный upstream GUI, для Qt for Python действуют отдельные условия. Для распространения конкретной сборки проверяются лицензии и notices включённых библиотек и кодеков. [ONNX Runtime](https://pypi.org/project/onnxruntime/) · [OpenCV](https://opencv.org/license/) · [FFmpeg](https://ffmpeg.org/legal.html) · [Qt for Python](https://doc.qt.io/qtforpython-6/licenses.html)

Upstream предупреждает, что обычный первый запуск скачивает модели. Перед запуском для продуктовой оценки получите условия для конкретных весов и установите разрешённые файлы локально. Подтверждение основания использования даёт владелец теста. [Ручная установка](https://github.com/hacksider/Deep-Live-Cam#installation) · [Обращение за технической оценкой](https://www.insightface.ai/contact)

Для подтверждённого академического теста запустите `python3 prepare_models.py --download` из каталога скрипта. Команда без аргументов проверяет файлы офлайн. Установщик получает три файла общим размером 468 988 325 байт в `~/.cache/deepfake-demo/deeplivecam-models` и сверяет размер и SHA-256 каждого файла перед его заменой. FP16 опубликован автором Deep-Live-Cam, две модели buffalo_l взяты из зеркала Immich с условиями InsightFace. Используются неизменяемые ревизии с опубликованными LFS-указателями. [FP16 и контрольная сумма](https://huggingface.co/hacksider/deep-live-cam/commit/b7332ca6798d47fe7e4e69b80c8030a43583901c) · [Два файла buffalo_l и контрольные суммы](https://huggingface.co/immich-app/buffalo_l/commit/90852f0f71a1d31c01db30347ba314a4e88358d2)
