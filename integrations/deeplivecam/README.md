# Deep-Live-Cam в студии

Обработчик использует модель замены и наложение результата из [hacksider/Deep-Live-Cam](https://github.com/hacksider/Deep-Live-Cam/blob/08896a51c9a6198f50dc9f7508acf39fc460c8f1/modules/processors/frame/face_swapper.py). Камера поставляет кадр назначения. Источником служит выбранная фотография с одним лицом в центре или встроенный рисованный портрет. Браузер передаёт локальному обработчику центральный квадрат фотографии размером 256×256. Для замены лица браузер берёт центральный квадрат камеры 256×256. Выходная дорожка передаёт обработанный квадрат 256×256 без подписей. Улучшатели отключены.

Для каждого кадра обработчик заново определяет лицо и пять ориентиров с размером поиска 640×640. InSwapper использует эти ориентиры для замены лица в том же кадре.

## Подготовка

[Команды установки для macOS, Windows и Linux](INSTALL.md).

1. Возьмите публичные исходники `https://github.com/hacksider/Deep-Live-Cam.git` и переключитесь на ревизию `08896a51c9a6198f50dc9f7508acf39fc460c8f1`. Каталог по умолчанию — `~/.cache/deepfake-demo/Deep-Live-Cam`. Можно указать другой через `DLC_REPO`.
2. Используйте отдельное 64-битное Python-окружение checkout. На macOS/Linux запуск выбирает `venv/bin/python`, на Windows — `venv/Scripts/python.exe`. Для другого окружения задайте `DLC_PYTHON`. На Apple Silicon сервис пробует Core ML для поиска и замены лица. Остальные платформы и резервный режим используют CPU. Подготовленные графы хранятся рядом с локальными весами в .studio-coreml-v1. Поле provider в /health показывает выбранный режим. На Windows требуется совместимый VC++ Runtime, на Apple Silicon — arm64 Python, на Linux — совместимая с CPU сборка ONNX Runtime.
3. Подготовьте **только для разрешённого сценария** InSwapper и анализатор buffalo_l. Из каталога этого адаптера `python prepare_models.py --download` загружает проверяемые файлы в `~/.cache/deepfake-demo/deeplivecam-models`; `python prepare_models.py` проверяет их офлайн. Другой каталог задаётся через `--dir` и `DLC_MODELS`. [Условия, контрольные суммы и источники](TERMS.md).
4. В корне студии выполните `yarn start:deeplivecam` и оставьте процесс открытым. В другом терминале запустите `yarn start`. Откройте http://localhost:3003/, включите камеру и выберите **Deep-Live-Cam · InSwapper**. После исправления зависимости перезапустите обработчик и повторно откройте список.

Сервис слушает 127.0.0.1:8766. `GET /health` возвращает `engine`, `ready`, причину недоступности и счётчик `swappedFrames`. Самопроверка запускает графы перед объявлением готовности. Включение открывает сеанс, выключение закрывает его и возвращает обычную камеру. Для выгрузки моделей из памяти остановите сервис через Ctrl+C.

## Проверка во встроенном браузере без камеры и звонка

В режиме разработки откройте http://localhost:3003/diagnostics/deeplivecam/. Страница использует основной интерфейс студии и движущийся вымышленный портрет, созданный для этого теста. Отправка формы звонка заблокирована, физические устройства не запрашиваются. Выберите Deep-Live-Cam, включите и выключите его. Страница считает кадры с порта 8766, проверяет изменение пикселей в центральной области лица, и показывает прирост счётчика обработчика. Эта страница не входит в production-сборку.
